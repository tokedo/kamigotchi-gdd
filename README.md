# Kamigotchi GDD

Technical Game Design Document for [Kamigotchi](https://kamigotchi.io/) — a
pure on-chain MMORPG on Yominet.

Extracted from source code at commit `ffda3963`.

## What's Here

- `mechanics/` — 53 mechanic files covering all game systems with formulas,
  configs, and source citations
- `catalogs/` — complete game data: 179 items, 72 skills, 195 quests, 71 rooms,
  64 nodes, 135 traits, 41 recipes, 3 factions, 2 NPCs, 18 shop listings
