## Overview

The `Kami721` contract is the ERC-721 NFT implementation for Kamis. It extends
OpenZeppelin's `ERC721Enumerable` (for token enumeration) and `ERC2981` (for
on-chain royalties). The contract uses a **two-state ownership model**: Kamis
are either **in-game** (staked, held by the contract) or **external** (held by
the player's EOA).

**Max supply: 22,222**

Token name: `"Kamigotchi"`, symbol: `"KAMI"`

## Two-State Ownership

| State | Token Held By | Source of Truth | Transfer Rules |
|---|---|---|---|
| In-game (staked) | `Kami721` contract (`address(this)`) | ECS components | Only MUD systems can modify |
| External (`721_EXTERNAL`) | Player's EOA | ERC-721 ownership | Standard ERC-721 transfers |

In-game Kamis cannot be transferred via standard ERC-721 methods — the
`_transfer` override checks `isOutOfWorld` and reverts if the Kami is staked.

> Source: `Kami721.sol:19–41, 150–153`

## Staking (Bridge In)

`Kami721StakeSystem.execute(tokenIndex)`:

1. Verify account is in **Room 12** (the bridge room)
2. Verify caller is the ERC-721 owner of the token
3. Verify Kami is not already linked to an account
4. Cancel any active marketplace listings for this Kami
5. Verify Kami is not already in-world
6. Set Kami's `IDOwnsKami` to the caller's account ID (ECS ownership)
7. Transfer ERC-721 token from player to `Kami721` contract
8. Log staking

Supports batch staking via `executeBatch(tokenIndices[])`.

> Source: `Kami721StakeSystem.sol:26–61`

## Unstaking (Bridge Out)

`Kami721UnstakeSystem.execute(tokenIndex)`:

1. Verify account is in **Room 12**
2. Verify Kami is owned by caller's account (ECS)
3. Verify Kami state is `RESTING`
4. Verify Kami is not **soulbound** (`LibSoulbound.verify`)
5. **Force-unequip all items** back to the account's inventory
   (`LibEquipment.unequipAll`) — equipment cannot be bridged out with the Kami
6. Remove Kami from ECS (clear account link, set state to `721_EXTERNAL`)
7. Transfer ERC-721 token from `Kami721` contract to player's EOA
8. Emit metadata update event
9. Log unstaking

Supports batch unstaking via `executeBatch(tokenIndices[])`.

> Source: `Kami721UnstakeSystem.sol:29–67`

## Minting

`Kami721.mint(to, id)` — writer-only:
- Verifies `totalSupply() < MAX_SUPPLY` (22,222)
- Mints token to the specified address

`Kami721.mintBatch(to, ids[])` — writer-only:
- Verifies `totalSupply() + ids.length <= MAX_SUPPLY`
- Mints all tokens to the same address

During creation, Kamis are minted to `address(Kami721)` (staked in-game from
birth).

> Source: `Kami721.sol:88–97`

## Royalties

Default royalty: **3.33% (333 basis points)** — set in constructor to the
contract owner.

| Function | Description |
|---|---|
| `setDefaultRoyalty(recipient, feeNumerator)` | Update default royalty (owner only) |
| `deleteDefaultRoyalty()` | Remove default royalty (owner only) |
| `setTokenRoyalty(tokenId, receiver, feeNumerator)` | Set per-token royalty (owner only) |
| `resetTokenRoyalty(tokenId)` | Reset per-token royalty (owner only) |

> Source: `Kami721.sol:77–138`

## External Transfers

`Kami721TransferSystem` provides batch transfer utilities for external (unstaked)
Kamis:

| Function | Description |
|---|---|
| `batchTransfer(tokenIndices[], to)` | Transfer multiple Kamis to one address |
| `batchTransferToMany(tokenIndices[], to[])` | Transfer Kamis to different addresses |

These only work for external Kamis and require prior approval.

> Source: `Kami721TransferSystem.sol:19–43`

## Metadata

Metadata is served via a **system contract** (`Kami721MetadataSystem`) for
upgradability. The `tokenURI()` override on `Kami721` delegates to this system.

### Metadata Format

On-chain JSON (base64 encoded):

```json
{
  "external_url": "https://kamigotchi.io",
  "name": "{kamiName}",
  "description": "a lil network spirit :3",
  "attributes": [
    {"trait_type": "Body", "value": "{bodyName}"},
    {"trait_type": "Color", "value": "{colorName}"},
    {"trait_type": "Face", "value": "{faceName}"},
    {"trait_type": "Hand", "value": "{handName}"},
    {"trait_type": "Background", "value": "{bgName}"},
    {"trait_type": "Body Affinity", "value": "{bodyAffinity}"},
    {"trait_type": "Hand Affinity", "value": "{handAffinity}"},
    {"trait_type": "Breed", "value": "PURE|MIXED"},
    {"trait_type": "Health", "value": 50},
    {"trait_type": "Power", "value": 10},
    {"trait_type": "Violence", "value": 10},
    {"trait_type": "Harmony", "value": 10},
    {"trait_type": "Level", "value": 1}
  ],
  "image": "https://{BASE_URI}/{mediaURI}.gif"
}
```

**Breed** is derived from affinities: `PURE` if body and hand affinity match,
`MIXED` otherwise.

`emitMetadataUpdate(id)` fires an ERC-4906 `MetadataUpdate` event to notify
marketplaces when on-chain state changes.

> Source: `LibKami721.sol:82–261`, `Kami721MetadataSystem.sol:21–23`

## In-World Check

`Kami721IsInWorldSystem.isInWorld(petIndex)` — view function used by the
`Kami721` contract's transfer modifier to block transfers of staked Kamis.
Delegates to `LibKami.isInWorld()`.

## Access Control

The `Kami721` contract uses `ProxyPermissionsERC721Component` for access:

| Modifier | Who | Used For |
|---|---|---|
| `onlyWriter` | Approved system contracts | mint, stakeToken, unstakeToken, emitMetadataUpdate |
| `onlyOwner` | Contract owner | Royalty management |
